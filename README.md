Stack

This project creates a Stack class to be used as a data structure simmilar to the Stack class implimentation by the C++ standard library. The stack class is built using the deque class as a foundation for the data structure.

stack.h is the header file which contains the definitions for the methods implimented by the stack class.
stack.hpp contains the implimentations of the stack class methods and builds the data structure.
in2post.cpp uses implimentation of the stack class to convert infix expressions into postfix expressions. This contains a main function that is run in the produced main executable.
makefile is used to create main.exe using the make command as an executable that can be run.
analysis.txt provides the time complexity analysis of the clear function implimented by the stack class.
